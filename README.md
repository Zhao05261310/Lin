# Lin：AI 協作工作台

讓多個 AI 一起討論（平行回答、匿名互評、接力、分工），以及能在你指定的工作資料夾裡實際讀檔、改檔、執行指令的 Agent。另外有訓練工作室，可以用自己的顯示卡或雲端 GPU 做語言模型、語音、圖片與影片的生成和 LoRA 訓練。

整個程式是單一檔案 `AI協作.py`，只用 Python 內建模組（tkinter），不需要安裝任何套件。需要 Python 3.10 以上，主要在 Windows 上使用，Linux／macOS 也能執行。

## 快速開始

```
python AI協作.py
```

第一次開啟後，到「設定 → 模型與 API」新增 AI。完整使用說明請看 [`AI協作使用說明.md`](AI協作使用說明.md)。

```
python AI協作.py --selftest
```

這行會跑自我測試（100 多項，不需要網路或金鑰）。

## API 金鑰

- 金鑰放在**環境變數**裡，例如 `NVIDIA_API_KEY`、`OPENAI_API_KEY`、`GROQ_API_KEY`。設定檔只記環境變數的**名稱**，不存金鑰本身。
- 也可以在欄位裡直接貼上金鑰，但只在這次執行時使用，不會存檔。
- 送給模型的訊息、對話紀錄和工具輸出裡，看起來像金鑰的字串會先被遮蔽。
- 本機模型（Ollama、LM Studio 等）不需要金鑰。

## 主要功能

- **AI 討論**：
  - 模式有平行回答、平行＋彙整、互評修正＋彙整、接力精修、分工合作。
  - 主持 AI 會判斷問題需不需要討論；各 AI 的結論有分歧時會標出來。
- **Agent**：
  - 可以列目錄、讀檔、搜尋、修改檔案（修改前自動備份，可以一鍵復原）、執行指令、上網查資料，也能把問題交給 AI 討論團。
  - 刻意沒有刪除檔案的功能；危險的指令、讀取金鑰檔、提示注入都會先擋下或先問你。
- **外部工具（MCP）**、**排程**、**自動更新**（驗證 SHA-256）、**匯出**（Markdown／HTML／PDF）。
- **訓練工作室**：
  - 語言模型與 QLoRA 微調（可以匯入 Ollama）。
  - 語音生成與聲音訓練（F5-TTS）。
  - 圖片生成（SD 1.5／SDXL／SD 3.5／FLUX）與圖片 LoRA 訓練。
  - 影片生成（Wan／LTX／CogVideoX）與影片 LoRA 訓練。
  - 訓練用的 PyTorch 等套件只裝在你指定的 Python 環境裡，本程式本身仍然不需要套件。
- **正確率實測**：用能自動評分的題目，量你的模型、團隊討論模式與 Agent 答對多少。

## 隱私

- 所有設定、對話紀錄、日誌、備份、訓練資料和生成的作品，都只存在你自己的電腦上（程式資料夾，或你在訓練工作室指定的資料夾）。
- 本程式不會把任何資料傳到作者這邊，只會連到你自己設定的 AI 服務、你要求的網頁搜尋，以及檢查更新的 GitHub。
- 這些檔案都列在 `.gitignore`，參與開發時也不會被提交。

## 開發

- `src/` 是分段原始碼，改完執行 `python build.py --test`：會組合成 `AI協作.py`、產生 `AI協作.py.sha256`（自動更新時比對用），並跑自我測試。
- 推送後，GitHub Actions 會在 Windows 與 Ubuntu（Python 3.10、3.13）自動測試，包括真的開啟介面的冒煙測試，以及用極小模型跑完整個訓練流程。
- 拓樸圖的動態角色在 `機器人動畫/`。沒有這個資料夾時，程式會改用內建繪製的造型。
- 這個專案的程式碼與角色圖片，大部分是在 Anthropic 的 Claude 協助下產生的；圖片帶有 C2PA 內容憑證，標示它是由 AI 產生的。
